# Практические работы по базам данных

Отчёты по практическим работам №4–8 в формате Word.

Чтобы скачать все файлы, нажмите **Code → Download ZIP**.
Чтобы скачать отдельный отчёт, откройте его и нажмите **Download raw file**.

## Лабораторные работы

[Готовые отчёты ЛБ1–ЛБ8](Лабораторные/) · [Скачать Word-файлы и SQL архивом](Лабораторные_1–8_документы.zip)

ЛБ1 сохранена без изменений. ЛБ2–ЛБ8 выполнены в PostgreSQL 17.11 и pgAdmin 4 9.10: команды SQL, фактические результаты, 29 скриншотов, выводы и ответы на контрольные вопросы. В ЛБ7 использована официальная демонстрационная база, в ЛБ8 — два независимых подключения и дополнительный уровень Serializable.
