# Практические работы по базам данных

Отчёты по практическим работам №4–8 в формате Word.

Чтобы скачать все файлы, нажмите **Code → Download ZIP**.
Чтобы скачать отдельный отчёт, откройте его и нажмите **Download raw file**.

## Лабораторные работы

[Документы ЛБ1–ЛБ8](Лабораторные/) · [Скачать архив Word-файлов](Лабораторные_1–8_документы.zip)

ЛБ1 — исходный готовый отчёт. ЛБ2–ЛБ8 — оформленные документы для пошагового выполнения в pgAdmin 4: теория, задания, ответы на вопросы и места для SQL, результатов и скриншотов. Практическая часть и итоговые выводы будут добавляться после выполнения.
