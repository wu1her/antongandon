- **ЛБ2–ЛБ8** — подготовленные документы по структуре ЛБ1: титульный лист, цель из методички, краткая теория, подробный порядок выполнения, места для SQL и скриншотов, раздел вывода, контрольные вопросы с ответами.

## Порядок работы

1. ЛБ2: подготовка отдельной базы `fitness_labs`, типы данных, три выборки и полнотекстовый поиск.
2. ЛБ3: создание, удаление и модификация учебных таблиц.
3. ЛБ4: восемь запросов с различными соединениями.
4. ЛБ5: десять подзапросов.
5. ЛБ6: десять примеров создания индексов — по два для обычных, многоколоночных, уникальных, выражений и частичных; измерения и удаление индекса.
6. ЛБ7: все группы примеров из методички на официальной демобазе `demo`, затем пять собственных опытов оптимизации.
7. ЛБ8: опыты Read Uncommitted, Read Committed и Repeatable Read в двух независимых подключениях, COMMIT и ROLLBACK. Serializable — дополнительное задание. Контрольные вопросы сохранены из методички, хотя в ней они посвящены оптимизации.

Тема собственной базы — фитнес-клуб, в продолжение ЛБ1. Учебные объекты последующих работ разделяются схемами lab02–lab08. Существующая база не удаляется.

Код будет предоставляться блоками для Query Tool в pgAdmin 4. Метакоманды psql (`\connect`, `\d`, `\di`, `\timing`) в Query Tool не выполняются: подключение выбирается интерфейсом, структура проверяется SQL-запросами, планы — EXPLAIN. Синтаксис SQL и состав заданий сохраняются по методичке.
