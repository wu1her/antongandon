# Лабораторные работы по базам данных

Григорьев А. А., ПИ-2-25.

ЛБ1 — исходный отчёт, сохранённый без изменений. ЛБ2–ЛБ8 содержат цель, теорию, выполненные команды SQL, реальные результаты, скриншоты pgAdmin 4, вывод и ответы на контрольные вопросы. Всего в новых отчётах 29 скриншотов.

Среда: PostgreSQL 17.11 и pgAdmin 4 9.10. Предметная область — фитнес-клуб. В ЛБ7 также использована официальная база demo-small-20170815 с https://edu.postgrespro.ru/demo-small.zip.

В папке SQL находятся команды для повторения опытов. Начальная схема предназначена для новой пустой базы; повторный запуск CREATE на существующих объектах требует подготовки новой учебной копии. Создание базы выполняется отдельно. Блоки с ожидаемыми ошибками запускаются отдельно от корректных команд.

ЛБ7 выполняется в двух базах: demo и fitness_labs. ЛБ8 требует двух независимых Query Tool — A и B; команды запускаются в указанном порядке, а не всем файлом сразу. Ожидание второго UPDATE снимается фиксацией первого сеанса.

Скриншоты также доступны отдельно в папке «Скриншоты». Для отдельных шагов ЛБ2 сохранена папка «Скриншоты_ЛБ2».
