# Лабораторная работа №4, вариант №8

Отчёт Word, две программы C# и настоящие скриншоты компиляции, выполнения и онлайн-проверки.

## Запуск

Требуется .NET 8 SDK или более новая среда с поддержкой net8.0. Откройте терминал в папке `Код/Генератор` и выполните `dotnet run`. Для второй программы выполните ту же команду в папке `Код/Аутентификация`.

В Visual Studio можно открыть соответствующий PasswordLab.csproj. Проекты независимы: файлы двух программ не нужно объединять.

Для проверки аутентификации верный учебный пароль — `aodg`. Другой ввод должен дать сообщение «пароль неверен».

Исходный сайт методички направляет на Security.org; скриншоты получены на действующем сервисе. Исходники программ не обращаются к сети.
