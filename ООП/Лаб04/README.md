# ООП. Лабораторная работа №4. Вариант №8

Отчёт оформлен по структуре Лаб02 и Лаб03. В нём три задачи, алгоритмы, листинги, исходные данные, текстовые результаты контрольных запусков и диаграммы классов. Скриншоты программы не добавлены.

## Файлы

- `Код/House.cs`, `DistrictHouse.cs` — задача 1.
- `Код/Parall.cs`, `Kub.cs` — задача 2.
- `Код/Tax.cs`, `Privilege.cs` — задача 3.
- `Task1.cs`, `Task2.cs`, `Task3.cs` — выполнение соответствующего задания методом Run.
- `Program.cs` — один Main с переключаемыми вызовами.
- `Диаграммы/` — диаграммы трёх иерархий в PNG, SVG и исходном формате DOT; они добавлены в проект как файлы.

## Запуск

Открой `Код/Lab4.csproj` в Visual Studio либо выполни `dotnet run` в папке `Код` при установленном .NET 8 SDK. В Program.cs по умолчанию включена задача 1. Для задачи 2 закомментируй обе строки с task1 и раскомментируй обе строки с task2. Для задачи 3 оставь активными обе строки с task3.

Если добавляешь исходники в уже существующий проект, все классы можно оставить в пространстве имён `Lab4`, а в своём Program.cs добавить `using Lab4;`. Сам Main из приложенного Program.cs тогда переносить не требуется: достаточно нужной пары строк вызова. В проекте должен быть один используемый Main.

Исходные данные генерируются случайно, поэтому вывод разных запусков может различаться. Текущий год берётся через DateTime.Now.Year. В House год постройки меньше текущего, в Kub три стороны всегда одинаковые. В CalculateTaxVip при наличии льготы используется половина обычного налога, а при отсутствии — обычная сумма.
