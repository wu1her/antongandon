КУРСОВАЯ РАБОТА. ЭТАП 2 — ИНДЕКСЫ

В комплекте находится обновлённая пояснительная записка в Word и PDF,
полный набор SQL-файлов 00–05 и два реальных скриншота Query Tool pgAdmin 4.
Сворачивание заголовков Word отключено. Предыдущая редакция сохранена отдельно.

ЕСЛИ БАЗА ЭТАПА 1 УЖЕ СОЗДАНА
1. Подключиться к gym_course, открыть Query Tool.
2. Выполнить файл SQL/04_Индексы.sql один раз.
3. Выполнить файл SQL/05_Проверка_индексов.sql целиком.
   Этот эксперимент можно повторять после завершения предыдущего запуска.

ЕСЛИ БАЗЫ ЕЩЁ НЕТ
1. В Query Tool базы postgres выполнить 00_Создать_базу.sql вне транзакции.
2. Подключиться к новой базе gym_course.
3. Последовательно выполнить 01, 02, 03, 04 и 05.
   Файлы 01, 02 и 04 рассчитаны на однократное выполнение.

ЧТО ДЕЛАЕТ ФАЙЛ 04
Создаёт восемь B-tree-индексов для внешних ключей и один частичный
B-tree по времени неотменённых занятий. Два других внешних ключа уже
покрыты индексами UNIQUE и EXCLUDE. Индексы PK и UNIQUE автоматически
созданы PostgreSQL. GiST-индекс subscriptions_no_overlap создан в файле 01.
Итого: 27 B-tree-индексов и один GiST-индекс; has_index = true для всех 10 FK.
На 15 строках Seq Scan допустим — это выбор планировщика для малого объёма.

ЧТО ДЕЛАЕТ ФАЙЛ 05
Создаёт временные таблицы по 20 000 синтетических строк и показывает
EXPLAIN (ANALYZE, BUFFERS) до/после создания временных индексов.
Для B-tree выбирается 151 занятие, для GiST — один абонемент.
В конце ROLLBACK удаляет временные таблицы и их индексы.
Постоянные данные и журнал аудита не дополняются тестовыми строками.
Во вкладке Data Output виден план последнего запроса; результаты отдельных
запросов удобно смотреть, выполняя файл последовательно по блокам в одном
Query Tool. BEGIN и ROLLBACK ограничивают весь эксперимент.
На скриншотах COSTS OFF и TIMING OFF скрывают оценки стоимости и время
отдельных узлов; Execution Time и BUFFERS остаются. Сами SELECT совпадают
с файлом 05. Для восстановления временной таблицы нужно выполнить её
подготовительный блок, а не один SELECT после завершённого ROLLBACK.

ЧТО ПОКА НЕ ЗАВЕРШЕНО
Полный набор бизнес-триггеров, не менее 10 нетривиальных запросов,
представления и три роли, итоговое заключение и презентация.
Правила полной оплаты, вместимости, активности и расписания сохранены,
но пока не защищены полным комплектом триггеров для любых изменений.
Следующий этап — бизнес-триггеры и проверки запретов.
